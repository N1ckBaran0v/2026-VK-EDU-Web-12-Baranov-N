# Проект по курсу "Веб-технологии"

Учебный проект по курсу "Веб-технологии".

## Запуск

1. Склонируйте репозиторий:

Для этого либо скачайте ветку как архив, распакуйте и откройте, либо скопируйте ссылку на клонирование репозитория (https или ssh), после чего введите в командной строке:

```bash
git clone <url-репозитория>
cd 2026-VK-EDU-Web-12-Baranov-N
```

2. Откройте `public/index.html` в браузере.

## Страницы

| Страница   | Файл                   | Описание                                   |
|------------|------------------------|--------------------------------------------|
| `base`     | `public/base.html`     | Базовый шаблон страницы                    |
| `index`    | `public/index.html`    | Главная страница со списком новых вопросов |
| `hot`      | `public/hot.html`      | Страница со списком популярных вопросов    |
| `tag`      | `public/tag.html`      | Страница со списком вопросов по тегу       |
| `question` | `public/question.html` | Страница отдельного вопроса                |
| `ask`      | `public/ask.html`      | Форма создания вопроса                     |
| `login`    | `public/login.html`    | Страница входа                             |
| `signup`   | `public/signup.html`   | Страница регистрации                       |
| `profile`  | `public/profile.html`  | Страница профиля                           |
